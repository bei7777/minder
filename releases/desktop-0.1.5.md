# Minder 桌面版 0.1.5

2026 年 11 月 25 日在 Apple 芯片 Mac、macOS 15.3 上验收。应用运行代码对应提交 `78ccb26`，使用 Pi SDK 和 0.1.4 终端版的七个运行时包。桌面更新使用原有本地配置和资料目录。[macOS 安装包](https://github.com/bei7777/minder/releases/download/desktop-v0.1.5/Minder-0.1.5-macos-arm64.dmg)

| 操作 | 成品验证 |
| --- | --- |
| 首次设置 | 在真实的 macOS 文件选择面板选取资料目录和供应商 JSON，选择模型，点击保存。应用进入对话页，光标位于输入框，磁盘上的配置与选择一致。 |
| 已有配置 | 使用 0.1.4 CLI 生成的配置打开应用。在设置页重新保存同一连接后，原配置文件时间戳、对话草稿和模型验证结果均得到保留。 |
| 文件监听 | 4,000 份实际 Markdown 文件的变动全部被记录。监听期间主进程完成 28 次测试请求，最长 65 毫秒。 |
| 真实对话 | 从应用界面连接 `dmxapi / deepseek-flash-guan`。验证后直接在对话输入框发送任务。第一轮收到 102 个文本片段，完成文件写入并显示 Markdown 标题。第二轮在重新保存设置之后正确复述随机值。撤销后文件逐字节与原文一致，停止生成和新建对话通过验证。 |
| 内置功能 | 在文件记录检查差异并撤销。在记忆审阅接受提议并从 SQLite 检索。在设置中保存提醒规则，用真实目录事件生成一份可送回输入框的草稿。 |
| 安装 | 挂载 DMG，复制应用至独立 APFS 卷，卸载 DMG，再用 Launch Services 启动新副本，进入首次设置。已校验磁盘映像、应用签名和包内 SQLite FTS5。 |
