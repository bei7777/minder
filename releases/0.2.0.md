# Minder 0.2.0

[macOS 安装包（Apple 芯片）](https://github.com/bei7777/minder/releases/download/v0.2.0/Minder-0.2.0-macos-arm64.dmg) · [终端发行包](minder-0.2.0.tar.gz)

可以直接问“这个目录里有哪些文档”。Minder 会列出你授权的资料目录，通过实际文件名查找文档。可以告诉它“下周三提醒我核对投稿附件”，登记委托后，在以后的对话中修改下一步、调整时间或标记完成。

打开 Mac 应用的“委托”可以查看和编辑待办事项。到期事项进入本机收件箱，受免打扰时间控制。关闭窗口后应用继续检查跟进时间，使用 Command-Q 退出后，下次启动时补查。已安装 0.1.5 的用户可以退出 Minder，将 DMG 中的应用拖至“应用程序”并选择替换，原有配置可继续使用。在“设置 → 内置能力”可核对桌面和终端版本。
